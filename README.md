# green-software-champions

[![Build](https://github.com/retit/green-software-champions/actions/workflows/build.yml/badge.svg)](https://github.com/retit/green-software-champions/actions/workflows/build.yml)
The solution centers on a leaderboard that aggregates carbon footprint data from cloud providers for individual teams. Two key metrics are presented: the team's total cloud carbon footprint and the reduction in their footprint over the last period. Based on their position on the leaderboard, teams can earn achievements that recognize progress.
